## Section 1: 신약 트렌드 (New Drug & Pipeline Trends)

### 1-A. BMS Admilparant — Phase 3 ALOFT-IPF 결과 발표

**헤드라인:** BMS의 IPF 치료제 admilparant, 60mg 용량에서 Phase 3 일차 endpoint 달성 — 120mg은 실패

**배경:**
Admilparant는 [[BMS]]가 개발 중인 lysophosphatidic acid receptor 1 (LPAR1) 길항제(antagonist)다. IPF(Idiopathic Pulmonary Fibrosis, 특발성폐섬유증)는 폐 조직이 점진적으로 섬유화되어 호흡 기능이 저하되는 진행성 치명 질환으로, 5년 생존율이 약 30~50%에 불과하다. LPAR1은 섬유화 과정에서 근섬유아세포(myofibroblast) 활성화와 폐 세포 이동을 촉진하며, 이를 차단하면 섬유화 진행을 억제할 수 있다는 기전이다.

**데이터 요약:**
- **일차 endpoint:** 52주 시점 FVC(forced vital capacity, 노력성폐활량) 절대 변화량
- **60mg BID:** 통계적으로 유의한 개선 달성 ✅
- **120mg BID:** FVC 감소 둔화 관찰되었으나 통계적 유의성 미달 ❌
- **안전성:** 양쪽 용량 모두 well-tolerated; 단, 한국 바이오스펙테이터에 따르면 EU 프로토콜 수정 과정에서 간독성 관련 환자 사망 1건이 보고됨 (영문 1차 자료 미확인, 요주의)
- **대규모 시험:** 약 1,255명의 IPF 성인 환자 등록
- **다음 단계:** 상세 데이터는 향후 학회에서 발표 예정; 동반 ALOFT-PPF 시험(PPF: Progressive Pulmonary Fibrosis) 결과는 2027년 초 예상

**BD 관점:**
용량 분리(dose dissociation) 결과는 규제 전략 복잡성을 높인다. BMS는 60mg 단독으로 NDA/MAA 제출이 가능하지만, 120mg의 실패는 best effective dose를 놓쳤을 가능성을 시사해 시장 침투 잠재력을 낮춘다. IPF 시장은 현재 nintedanib(Boehringer)과 pirfenidone(Roche)이 표준 치료제로 자리잡고 있으며, 작용 기전이 달라 병용 요법 가능성도 BD 관점에서 검토 가치가 있다. 경쟁자 대비 차별점 증명이 launch 성패를 가를 것이다.

**경쟁 구도:**
1. **Nintedanib (Ofev)** — Boehringer Ingelheim; VEGFR/PDGFR/FGFR 억제제, 이미 IPF 표준치료
2. **Pirfenidone (Esbriet/Pirespa)** — Roche; 항섬유화·항염증, 글로벌 시장 1위
3. **Pamrevlumab** — FibroGen; CTGF 항체, Phase 3 ZEPHYRUS-1/2 결과 공개 대기 중

### 1-B. BMS RYZ101 — Phase 3 ACTION-1 결과 (GEP-NETs)

**헤드라인:** BMS의 방사성 리간드 치료제 RYZ101, 위장관췌장 신경내분비종양 Phase 3에서 일차 PFS endpoint 달성

**배경:**
RYZ101은 somatostatin receptor (SSTR) 표적 [[방사성리간드치료제 (RLT)]]; actinium-225 탑재 알파 방출체(alpha emitter)다. Lutetium-177 기반의 베타 방출체(Lu-DOTATATE, Novartis의 Lutathera)와 달리, 알파 입자는 조직 투과 거리가 짧고 에너지가 높아 종양 국소 살상 효과가 더 강력할 것으로 기대된다. BMS는 2023년 RayzeBio 인수($4.1B)를 통해 이 자산을 확보했다.

**데이터 요약:**
- **일차 endpoint:** PFS(무진행생존기간) 통계적 유의한 개선 ✅
- **상세 수치:** 미공개 (향후 학회 발표 예정)
- **다음 단계:** BMS 는 NDA 제출 준비 시작 예상

**BD 관점:**
방사성리간드치료제 시장은 Novartis(Lutathera, Pluvicto)가 선점한 고성장 영역이다. BMS가 알파 방출체로 차별화에 성공한다면 이 공간에서 경쟁력 있는 후발주자가 된다. Actinium 기반 알파 치료제 공간에는 진입장벽이 높아(제조·공급망 복잡성) 라이선싱보다 인수 전략이 선호되는 경향이 있다.

**경쟁 구도:**
1. **Lu-DOTATATE (Lutathera)** — Novartis; 베타 방출체, GEP-NETs 승인
2. **PNT2002** — POINT Biopharma/Lantheus; PSMA 표적 RLT (전립선암)
3. **FPI-2265** — Fusion Pharmaceuticals/AstraZeneca; Ac-225 PSMA 타겟

### 1-C. 이자-브렌(Iza-bren) — 이중특이적 [[ADC]] Phase 3 다중 양성 결과

**헤드라인:** Biokin의 EGFR/HER3 이중특이적 ADC iza-bren, TNBC와 폐암 Phase 3에서 모두 생존 개선

**배경:**
Izalontamab brengitecan(iza-bren, BL-B01D1)은 **EGFR와 HER3를 동시에 표적**으로 하는 최초의 이중특이적 [[ADC]]다. 항체 부분이 두 수용체에 결합하여 인터날리제이션(internalization) 후 DXd(topoisomerase I inhibitor) payload를 방출한다. 단일 표적 ADC 대비 HER3 발현 종양에서도 활성을 나타낼 수 있어 적응증 범위가 넓다는 것이 강점이다. BMS는 글로벌(중국 제외) 개발·판매권에 대한 파트너십을 체결한 상태다.

**데이터 요약 (PANKU-Breast02 — TNBC):**
- **ORR (객관적반응률):** 51.7% vs 화학요법
- **PFS 개선:** 71% 낮은 진행 또는 사망 위험
- **OS (전체생존기간):** 개선 관찰
- **주요 독성:** 혈액독성(grade ≥3) 흔함

**데이터 요약 (PANKU-Lung01 — NSCLC):**
- **PFS endpoint:** 달성 ✅
- **OS 추세:** 긍정적 경향 관찰
- Phase 3 네 번째 양성 결과

**BD 관점:**
이중특이적 ADC는 기존 monospecific ADC의 다음 세대로 급부상하고 있다. Iza-bren의 연속 Phase 3 성공은 이 플랫폼 기술에 대한 글로벌 BD 관심을 크게 높인다. 중국 biotech → 글로벌 Big Pharma 라이선싱 구조(BMS의 글로벌권 확보)의 전형적 사례로, payload/linker/표적 조합이 차별화된 ADC 자산은 upfront $150~300M 이상 기대 가능.

**경쟁 구도 — EGFR/HER3 ADC:**
1. **Trastuzumab deruxtecan (T-DXd, Enhertu)** — Daiichi Sankyo/AstraZeneca; HER2 타겟, 같은 DXd payload (범용 비교 기준)
2. **Patritumab deruxtecan (HER3-DXd)** — Daiichi Sankyo/Merck; HER3 단독 표적, NSCLC
3. **Amivantamab (Rybrevant)** — Janssen; EGFR/MET bispecific 항체 (ADC 아니지만 동일 공간)

### 1-D. Temab-A (ABBV-400) — FDA Breakthrough Therapy Designation

**헤드라인:** AbbVie의 c-Met ADC telisotuzumab adizutecan, 이전 치료받은 c-Met 발현 NSCLC에서 BTD 획득

**배경:**
Telisotuzumab adizutecan(Temab-A, ABBV-400)은 c-MET(mesenchymal-epithelial transition factor) 수용체를 표적으로 하는 [[ADC]]다. c-MET 과발현은 NSCLC 특히 EGFR wild-type 비편평상피 비소세포폐암에서 불량한 예후와 연관된다. DXd payload 탑재 ADC로, 기존 EGFR TKI 내성 기전 우회에 활용 가능하다. Phase 1 연구 결과를 기반으로 BTD를 획득했다.

**BD 관점:**
BTD는 FDA와의 긴밀한 협력 채널을 열고 rolling review 가능성을 높여 개발 timeline을 단축시킨다. c-MET ADC 공간은 경쟁이 심화되고 있으며, AbbVie는 이 자산으로 Imbruvica 특허 만료 이후 포트폴리오를 다각화하려는 전략이다.

**경쟁 구도:**
1. **Amivantamab + lazertinib** — Janssen; EGFR/c-MET bispecific + 3세대 EGFR TKI 병용
2. **Capmatinib (Tabrecta)** — Novartis; MET exon 14 skipping 돌연변이 NSCLC
3. **Tepotinib (Tepmetko)** — Merck KGaA; MET exon 14 NSCLC

### 1-E. Bepirovirsen — GSK, FDA BTD + Priority Review (PDUFA: Oct 26, 2026)

**헤드라인:** GSK/Ionis의 만성B형간염 치료제 bepirovirsen, 이번 주 FDA 결정 예정

**배경:**
Bepirovirsen은 HBV RNA를 표적으로 하는 antisense oligonucleotide(ASO)다. 기능적 치료(functional cure) — 즉 HBsAg 소실 — 을 목표로 하며, 기존 핵산 유사체(nucleoside analogue) 치료와 근본적으로 다른 기전이다. B-Well 1/2 Phase 3 시험을 기반으로 신청했다.

**BD 관점:**
만성B형간염은 글로벌 3억명 이상 감염, 특히 아시아에서 high unmet need다. 승인 시 RNAi(Vir/GSK의 VIR-2218 등)와 병용 요법 BD 기회가 열릴 수 있다. **PDUFA date: 2026년 10월 26일** — 이번 주 결정이 예상된다.

## Section 2: 글로벌 BD 딜 분석 (Global Pharma BD Deal Analysis)

### 2-A. BMS ↔ Hengrui — $15.2B 전략적 협업 (역대 최대 규모 중국 biotech 딜)

**딜 개요:**
[[BMS]]가 Hengrui Pharma로부터 13개 초기 단계(early-stage) 프로그램의 글로벌(중국 본토·홍콩·마카오 제외) 권리를 확보. 2026년 5월 발표, 7월 클로징.

**딜 구조:**
| 항목 | 금액 |
|------|------|
| Upfront (2026 Q3) | **$600M** |
| Anniversary payment (2027) | **$175M** |
| 2nd Anniversary (2028, 조기종료 없을 경우) | **$175M** |
| 조건부 마일스톤 | **최대 $14.3B** |
| Royalties | 티어드 로열티 (비공개) |
| **총 잠재 가치** | **$15.2B** |

**프로그램 구성:**
- Hengrui 제공: 항종양/혈액암 4개 + 면역 질환 4개 (BMS 제공) + 공동 발굴 5개 = 13개 총계

**왜 이 딜인가:**
BMS 관점에서는 2020년대 후반 Opdivo + Eliquis 특허 만료(patent cliff)를 앞두고 후기 임상 자산보다 저렴하지만 다양성이 높은 early-stage 포트폴리오를 확보하는 전략이다. Hengrui는 중국 내 막강한 규제·상업화 능력을 유지하면서 글로벌 시장 접근을 BMS라는 파트너를 통해 확보한다.

**밸류에이션 근거:**
- 13개 프로그램에 $600M upfront → 프로그램당 평균 $46M upfront
- Early-stage 포트폴리오 딜로는 이례적으로 큰 규모; 유사 딜로는 AstraZeneca-CSPC($5.3B, 2025), GSK-Hengrui($12.5B, 2025) 참고
- 마일스톤 비중($14.3B)이 80% 이상 → 실제 가치는 임상 성공률에 크게 의존 (early-stage PoS ~5~15%)
- 즉, 위험조정 후(risk-adjusted) 실제 기대가치는 $1.5~3B 수준으로 추정 가능

**리스크 요인:**
- Early-stage 자산 임상 실패율 높음 (일반적으로 Phase 1→NDA 성공률 ~10~12%)
- BMS가 2년 내 조기 종료 시 두 번째 anniversary 지급 불필요 → downside protection 있음
- 중국 IP 분쟁 리스크, 미중 관계 악화 시 공동개발 협력 차질 가능성

### 2-B. Hanmi Pharm ↔ Genentech (Roche) — HM17321 비만 라이선싱 ~$2.5B

**딜 개요:**
[[Hanmi Pharmaceutical|한미약품]]이 GLP-1/GIP/FGF21 삼중 작용제(triple agonist) HM17321(비만 치료 후보)의 글로벌 권리를 Genentech에 라이선싱.

**딜 구조:**
- **Upfront:** $190M
- **총 잠재 가치:** ~$2.5B (마일스톤 + 로열티 포함)

**왜 이 딜인가:**
Roche는 GLP-1 경쟁에서 Lilly/Novo Nordisk 대비 후발주자였으며, 한미약품의 독자적 비만 플랫폼 기술(long-acting platform, LAPSCOVERY)을 통해 빠르게 내재화하려는 전략이다. GLP-1 비만 시장은 2030년까지 $100B 이상 전망.

**밸류에이션 근거:**
- Tirzepatide(Lilly, $5B+ 연매출 예상) 성공에 따른 GLP-1/GIP 병용 옵션의 시장 가치 반영
- FGF21 추가(삼중 작용)는 간 섬유화·MASH 적응증 확장 가능성으로 premium 부여
- 유사 딜: 한미약품의 sonefpeglutide-Lilly($1.2B), OliX-2025 딜, 등

**리스크 요인:**
- GLP-1 시장 과열 — Novo Nordisk, Lilly, 한미, AZ, Pfizer 등 수십 개 후보 경합
- 삼중 작용 안전성 프로파일 (pancreatic/cardiac 모니터링)
- Phase 전환 실패 시 milestone 지급 없음

### 2-C. ABL Bio ↔ Eli Lilly — Grabody-B BBB Shuttle $2.6B

**딜 개요:**
ABL Bio가 혈뇌장벽(BBB: Blood-Brain Barrier) 통과 플랫폼 기술 "Grabody-B"의 라이선싱·공동연구 계약을 Eli Lilly와 체결. 총 잠재 가치 $2.6B.

**왜 이 딜인가:**
중추신경계(CNS) 질환 치료에서 BBB 통과는 고질적 난제다. Grabody-B는 transferrin receptor(TfR) 결합을 통해 BBB를 능동적으로 통과하는 이중특이적 플랫폼으로, Lilly의 알츠하이머/파킨슨 파이프라인에 적용 시 뇌 내 약물 농도를 획기적으로 높일 수 있다.

## Section 4: 오늘의 BD 역량 심화 — Deal Valuation: rNPV 계산법

### 4-1. 오늘의 BD 스킬: [[Deal Valuation]] — rNPV (Risk-Adjusted NPV)

### 4-2. 실제 사례: BMS ↔ Hengrui $15.2B 딜

### 4-3. 개념 설명

[[rNPV]](risk-adjusted Net Present Value)는 신약 딜에서 가장 많이 쓰이는 가치평가 방법이다. 기본 NPV에 각 개발 단계별 **임상 성공 확률(Probability of Success, PoS)**을 곱하여 리스크를 반영한다.

**핵심 공식:**
```
rNPV = Σ [ Cash Flow_t × PoS_cumulative × (1 / (1+r)^t) ]
```
- `PoS_cumulative`: 현재 단계에서 NDA 승인까지 모든 단계의 성공 확률 곱
- `r`: Discount rate (바이오파마 업계 통상 10~15%)
- `t`: 시간 (년)

**업계 평균 PoS (단계별 NDA 승인 누적 확률):**
| 단계 | 단계 성공률 | NDA까지 누적 PoS |
|------|------------|-----------------|
| Preclinical → Phase 1 | ~63% | ~10~12% |
| Phase 1 → Phase 2 | ~52% | ~16~20% |
| Phase 2 → Phase 3 | ~29% | ~40~50% |
| Phase 3 → NDA | ~58% | ~85~90% |
| NDA → 승인 | ~85~90% | ~85~90% |

### 4-4. 실전 적용: BMS-Hengrui 딜 back-of-envelope rNPV

**가정:**
- 13개 early-stage 프로그램 (대부분 Phase 1 이전 또는 Phase 1 진입 단계)
- PoS (현재 단계 → 시장): 평균 **10%** (early-stage 보수적 가정)
- 각 프로그램 peak sales 가정: **$500M** (중간값; 항암·면역 혼합)
- Royalty rate (BMS → Hengrui): 10% (추정)
- Peak sales 도달: 15년 후
- Discount rate: **12%**

**Step-by-step:**

**Step 1: Peak Year Royalty 계산**
```
Peak royalty = $500M × 10% = $50M/년 × 13개 = $650M/년 (성공 시 gross)
```

**Step 2: 위험조정**
```
Risk-adjusted peak royalty = $650M × 10%(PoS) = $65M/년
```

**Step 3: NPV (단순화)**
```
NPV = $65M × 1/(1.12^15) ≈ $65M × 0.183 ≈ $11.9M/year → perpetuity-like value
실제로는 제품 수명 20년 가정 시 NPV ≈ $65M × 7.25 (12% 20년 annuity factor) ≈ $471M
```

**Step 4: 비교**
```
BMS upfront = $600M > rNPV 추정 $471M → 프리미엄 지불?
```
→ **이유**: BMS는 단순 로열티 가치 이상의 전략적 가치(strategic premium)를 지불 — 파이프라인 다양성, 파트너 관계 자체의 가치, optionality

**Step 5: 실제 딜 가치와 비교**
```
$15.2B (headline) → 거의 전부 milestone 기반
$600M upfront ÷ 13개 = 프로그램당 ~$46M
→ Phase 1 진입 에셋의 upfront 시장가와 일치 (업계 $30~60M 범위)
```

**핵심 통찰:** 헤드라인 $15.2B는 언론용 숫자이고, 실제 BMS의 현금 부담은 $600M + $350M(anniversary) = **$950M**이며, 나머지는 성공 시에만 지급된다. BD 전문가는 항상 **upfront + near-term milestone**을 "실질 딜 규모"로 본다.
