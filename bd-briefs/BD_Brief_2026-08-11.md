## Section 1: 신약 트렌드 (New Drug & Pipeline Trends)

### 1-1. Iberdomide (BMS) — FDA Priority Review, PDUFA D-6 (8월 17일)

**헤드라인**: [[BMS]] 차세대 항암제 iberdomide, FDA Priority Review 진행 중 — CELMoD 계열 최초 승인 8월 17일 결정 임박

**배경**: Iberdomide는 CELMoD (Cereblon E3 Ligase Modulator) 계열 신약이다. 탈리도마이드 계열(Revlimid → Pomalyst)의 다음 세대로, ubiquitin-proteasome system을 통해 Ikaros와 Aiolos 전사인자를 선택적으로 분해시켜 다발성 골수종(Multiple Myeloma, MM) 세포를 사멸시킨다. Revlimid의 LOE(Loss of Exclusivity) 이후 BMS 혈액암 포트폴리오 핵심 축.

**데이터 요약**:
- 시험명: Phase 3 **EXCALIBER-RRMM** (NCT04975997)
- 비교군: IberDd (iberdomide + daratumumab + dexamethasone) vs. DVd (daratumumab + bortezomib + dexamethasone)
- 대상: Relapsed/Refractory Multiple Myeloma (RRMM)
- 규제 현황: FDA Breakthrough Therapy Designation + Priority Review 부여
- **PDUFA date: 2026년 8월 17일** (FDA Project Orbis: 다국가 동시 심사)
- NDA 수리: 2026년 2월

**BD 관점**: CELMoD 계열 최초 승인 신약이 될 경우 BMS는 Revlimid 이후 새로운 MM 치료 플랫폼 확보. Breakthrough Therapy Designation은 라이선스 딜에서 프리미엄 valuation의 법적·상업적 근거. 승인 시 연간 피크 매출 $3~5B 추정.

**경쟁 구도**:
- Mezigdomide (BMS 자체, 동일 CELMoD 계열, Phase 2 진행 중)
- Darzalex-based triplet regimens (J&J/Janssen, 현 표준치료)
- Carfilzomib combinations (Amgen, Kyprolis)

### 1-2. Izalontamab Brengitecan (Iza-Bren) — ASCO 2026 TNBC Phase 3 이중 Endpoint 달성

**헤드라인**: [[BMS]]의 EGFR×HER3 [[Bispecific ADC]] Iza-Bren, TNBC Phase 3에서 PFS 71% 개선 + OS 통계적 유의 달성 — 세계 최초 bispecific ADC Phase 3 이중 primary endpoint 성공

**배경**: Iza-Bren은 EGFR와 HER3를 동시에 표적하는 bispecific ADC (Antibody-Drug Conjugate)다. 기존 단일 표적 ADC와 달리 두 수용체를 동시 인식하여 종양 세포 특이성을 높이고 내성 발생을 억제한다. Payload는 MMAE 계열 tubulin inhibitor. BMS가 중국 바이오텍 SystImmune으로부터 $800M 규모 라이선싱 계약을 통해 확보한 에셋. ESCC (식도 편평세포암) 및 비인두암에서도 활성 확인.

**데이터 요약** (PANKU-Breast02, Phase 3, ASCO 2026 발표):
- 대상: 1~2 prior lines 치료 후 진행된 unresectable locally advanced / metastatic TNBC
- 무작위 배정: 418명 (iza-bren n=207 vs. physician's choice chemotherapy n=211)
- **PFS: HR 통계적 유의, 71% 개선** (vs. chemotherapy)
- **OS: 통계적 유의 개선** (세부 수치 NEJM/JCO 게재 예정)
- 비교대상 화학요법: eribulin, capecitabine, gemcitabine, vinorelbine
- 이는 Phase 3 bispecific ADC 연구 중 PFS + OS **이중 primary endpoint** 동시 달성 세계 최초 사례

**BD 관점**: TNBC는 HER2 음성/ER 음성/PR 음성으로 표적 치료가 극히 제한적인 고미충족 시장. Bispecific ADC의 Phase 3 성공은 플랫폼 자체 가치를 증명하며, 유방암 외 다른 암종(위암, 폐암, ESCC)으로 적응증 확장 가능성을 시사. SystImmune의 원개발 플랫폼 추가 자산에 대한 시장 관심 급증 예상.

**경쟁 구도**:
- Sacituzumab govitecan (TROP2 [[ADC]], Gilead/Trodelvy) — TNBC 기존 표준치료
- Datopotamab deruxtecan (Dato-DXd, TROP2 ADC, AstraZeneca/Daiichi Sankyo)
- Pembrolizumab + chemotherapy (MSD/Merck)

### 1-3. Ivonescimab — FDA BLA 수리 완료, PDUFA November 14, 2026

**헤드라인**: 중국발 PD-1/VEGF 이중항체 ivonescimab, 미국 FDA BLA 수리 — NSCLC 1차 치료 패러다임 변화 예고

**배경**: Ivonescimab은 PD-1과 VEGF를 동시에 차단하는 tetravalent bispecific antibody다. 기존에는 pembrolizumab(항PD-1)과 bevacizumab(항VEGF)을 별도 투여했으나, 이를 단일 분자로 통합. 핵심 mechanism: 종양 미세환경(TME)에서 VEGF 농도가 높을수록 PD-1 결합력이 협력적으로 높아지는 **cooperative binding** 특성 → 종양 부위에서 선택적 활성화. 중국 Akeso 개발, Summit Therapeutics가 글로벌(ex-China) 권리 보유.

**데이터 요약**:
- FDA BLA 수리 완료, **PDUFA: 2026년 11월 14일**
- HARMONi-2 (Lancet 게재): PD-L1-high NSCLC에서 pembrolizumab 단독 대비 PFS 통계적 유의 개선
- HARMONi-6 (ASCO 2026): 1L squamous NSCLC, ivonescimab+chemo vs. tislelizumab+chemo → **OS HR 0.53 (mOS 33.6개월 vs. 15.9개월)**
- 현재 16개 Phase 3 trial 동시 진행 중 (다중 암종)
- 중국 NMPA 승인 완료 (2024년 5월, EGFR 변이 비편평 NSCLC), 중국 국가보험 등재 (2024년 11월)

**BD 관점**: 중국에서 검증된 에셋이 미국 BLA 수리까지 성공한 대표적 China-to-Global 사례. 승인 시 NSCLC 1차 치료 대형 시장(연간 $5B+) 진입 가능. Keytruda 대비 superior PFS 데이터 → 라이선스 프리미엄 근거.

**경쟁 구도**:
- Pembrolizumab (Keytruda, MSD) — NSCLC 1L 시장 1위, 연간 ~$25B
- Atezolizumab + bevacizumab (Roche, IMpower 시리즈)
- PF-08634404 (Pfizer의 자체 PD-1/VEGF bispecific, Phase 2-3 진행 중)

### 1-4. Deramiocel — DMD 심근병증 세포치료제, FDA PDUFA 8월 22일 (이번 주 핵심 결정)

**헤드라인**: Duchenne 근육디스트로피 심근병증 세포치료제 deramiocel, FDA 결정 D-11일 — 희귀 신경근육질환 세포치료 최초 승인 가능성

**배경**: Deramiocel은 심장 유래 줄기세포(cardiosphere-derived cells, CDCs) 기반 세포치료제. DMD 환자에서 심근병증은 생존 결정 요인 중 하나. 2025년 CRL(Complete Response Letter) 발행 후, Phase 3 **HOPE-3** 추가 데이터 제출로 BLA 재심사 진행 중. Capricor Therapeutics 개발, 일본 Nippon Shinyaku와 미국/일본 상업화 협정 체결.

**데이터 요약**:
- HOPE-3 Phase 3: Primary endpoint 달성 + 모든 Type I error-controlled secondary endpoint 달성
- FDA Priority Review 부여, **PDUFA: 2026년 8월 22일**
- FDA Advisory Committee 개최: 2026년 7월 29일

**BD 관점**: 희귀 신경근육질환 세포치료제의 첫 FDA 승인 선례 창출 가능. Capricor-Nippon Shinyaku 파트너십은 희귀질환 BD에서 전형적인 "글로벌 상업화 파트너십 + 로열티" 구조의 교과서 사례.

## Section 2: 글로벌 BD 딜 분석 (Global Pharma BD Deal Analysis)

### 2-1. BMS × Hengrui — $15.2B 전략적 제휴 (2026년 5월)

**딜 개요**: [[BMS]]가 중국 최대 제약사 Jiangsu Hengrui Pharma와 13개 조기 단계 프로그램(oncology 4개, hematology 포함 / immunology 4개 BMS 보유 / 공동 발굴 5개)에 대한 글로벌 전략적 제휴 체결.

**딜 구조**:
| 항목 | 금액 |
|------|------|
| Upfront payment | **$600M** (즉시) |
| 1주년 지급 | $175M (2027) |
| 2주년 조건부 지급 | $175M (2028) |
| 총 근기 지급 | ~$950M |
| 마일스톤 포함 최대 총액 | **$15.2B** |
| Royalty | Hengrui → tiered royalties (ex-China 지역 순매출) |
| 지역 구조 | BMS: ex-China 권리 / Hengrui: Chinese rights to BMS drugs |

**왜 이 딜인가**:
- BMS: Revlimid LOE + Opdivo 경쟁 심화 → 파이프라인 보충 시급. Hengrui는 중국 내 빠른 POC 속도와 저비용 R&D가 강점 → "Buy China POC, Develop Globally" 전략.
- Hengrui: 글로벌 개발 자금 확보 + BMS의 글로벌 commercialization 역량 활용.

**밸류에이션 근거** ([[rNPV]] 관점):
- 13개 프로그램 × 평균 Phase 1 종양학 에셋 PoS (Phase 1→승인): ~7%
- 기대 승인 자산 수: ~0.9개
- 평균 피크 매출 종양학 자산: ~$1.5B/asset
- Royalty 20% 가정 × NPV factor 7 = rNPV ≈ $1.89B
- $600M upfront ÷ rNPV $1.89B ≈ **32%** → 경쟁 입찰 + 플랫폼 프리미엄 반영

**리스크 요인**:
- 지정학적 리스크: 미중 관계 악화 시 기술이전 제한 가능성
- Phase 1 자산 높은 attrition rate (종양학 ~93% 실패)
- IP 리스크: 중국 biotech IP 보호 수준 불확실성
- 13개 프로그램 동시 관리의 Portfolio execution risk

**📌 Section 2 Takeaways**

- **오늘 딜에서 배울 수 있는 딜 구조 패턴**: **"大 Upfront + 조기 단계 다수 에셋 묶음" 중국 out-licensing 패턴** — 2026년 최대 트렌드. 공통 구조: ① 조기 단계(Phase 1 이전~1) 다수 프로그램 묶음 ② 대규모 upfront ($500M~$1.2B) ③ 중국 지역 제외 ④ 개발 주도권은 중국 파트너 유지. 이는 "Chinese biotech POC → Global pharma scale-up" 분업 모델의 정착.

- **비슷한 에셋을 가진 한국 바이오텍 벤치마크**:

## Section 4: 오늘의 BD 역량 심화 — Deal Valuation (rNPV)

### 1. 오늘의 BD 스킬: [[Deal Valuation]] — rNPV (Risk-adjusted Net Present Value) 계산법

### 2. 실제 사례: BMS × Hengrui $15.2B 전략적 제휴

> BMS는 왜 Phase 1 이하 단계의 에셋 13개에 $600M upfront와 최대 $15.2B 딜 가치를 인정했을까?

이 질문에 답하는 핵심 도구가 **[[rNPV]]**다.

---

### 3. 개념 설명

**rNPV = NPV × Probability of Success (PoS)**

일반 NPV(Net Present Value)는 미래 현금흐름을 현재가치로 할인한다. 그러나 신약 개발은 각 임상 단계마다 실패 확률이 존재하므로, 각 단계별 **성공확률(PoS)**을 누적 곱하여 조정한다.

**임상 단계별 평균 성공 확률 (Industry Standard)**:

| 단계 | 다음 단계 성공률 | Phase 1 → 최종 승인 누적 확률 |
|------|----------------|-------------------------------|
| Phase 1 → Phase 2 | ~65% | — |
| Phase 2 → Phase 3 | ~40% | — |
| Phase 3 → NDA/BLA | ~65% | — |
| NDA → Approval | ~85% | — |
| **Phase 1 → 승인 (종양학)** | — | **~5~10%** |

> 종양학 적응증의 Phase 1→승인 누적 성공률은 약 **5~10%** (전체 치료 영역 평균 ~11.83%보다 낮음)

---

### 4. 실전 적용 — BMS-Hengrui 딜 rNPV 역산

**Step 1: Peak Sales 추정**

```
가정: 13개 프로그램 중 종양학/혈액암/면역학 에셋
평균 종양학 자산 피크 매출: $1.5B/asset (성공 시)
```

**Step 2: Probability of Success 적용**

```
Phase 1 이전~1 단계 자산 × 종양학 PoS 7% = 0.91개 예상 승인
기대 피크 매출 = 0.91 × $1.5B = $1.37B
```

**Step 3: NPV 계산**

```
Royalty rate 가정: 20%
Royalty 수입/year (peak): $1.37B × 20% = $274M
유효 매출 기간: 15년
WACC: 10%
PV factor (annuity): ~7.6

NPV ≈ $274M × 7.6 = $2.08B
```

**Step 4: rNPV (이미 PoS 반영)**

```
rNPV ≈ $2.08B
(Note: PoS는 Step 2에서 이미 적용됨)
```

**Step 5: Upfront 합리성 검증**

```
$600M upfront ÷ rNPV $2.08B = 28.8%
→ 업계 통상 upfront/rNPV 비율: 20~30%
→ BMS의 $600M upfront는 합리적 범위 내
→ 단, 플랫폼 프리미엄 + 경쟁 입찰 압력 반영 시 upper end에 위치
```

**결론**: BMS는 에셋 개별 가치 외에 ① Hengrui의 중국 R&D 속도 독점 접근권 ② 경쟁 입찰(GSK, AZ 등) 프리미엄 ③ 공동 발굴 5개 프로그램의 optionality 가치를 추가 지급한 것.
