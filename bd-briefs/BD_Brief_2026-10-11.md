#### 🔴 Tecentriq, 3기 대장암 보조요법으로 FDA 승인 — Roche/Genentech의 새 포지셔닝

**헤드라인**: Genentech의 Tecentriq(atezolizumab), MMR-결핍 Stage III 대장암 보조치료에 FDA 승인 (Oct 8)

**배경**:
Tecentriq은 PD-L1을 타깃으로 하는 checkpoint inhibitor다. 이번 승인은 특정 Stage III 대장암에서 플루오로피리미딘 + 옥살리플라틴(FOLFOX 계열) 병용 보조요법으로 사용된다. Roche의 Tecentriq은 폐암, 방광암, 유방암 등에서 이미 사용 중이지만, 대장암 적응증은 이번이 처음이다. MMR-결핍(dMMR) 환자 세그먼트는 PD-1/PD-L1 checkpoint 치료에 특히 반응이 좋다는 기존 연구들과 일관된다.

**데이터 요약**:
- Indication: dMMR/MSI-H Stage III 대장암, 보조요법
- Combination: Fluoropyrimidine + oxaliplatin 병용
- 구체적 임상 수치는 현재 보도에서 확인되지 않음 — BMS 내부 reference 시 원발 데이터 확인 필요

**BD 관점**:
Roche가 Tecentriq의 Life Cycle Management(LCM)을 통해 새 적응증으로 확장하는 전략. BMS의 Opdivo/Yervoy 대장암 적응증 전략과 직접 경쟁. dMMR 대장암은 PD-1/PD-L1 계열 전체의 주요 전장이 되고 있음.

**경쟁 구도**:
- MSD Keytruda (pembrolizumab): dMMR 대장암 1차 치료 선점
- BMS Opdivo + Yervoy: 대장암 1차 치료 CheckMate 8HW 결과 긍정적
- Roche Tecentriq: 이번 승인으로 보조요법 세그먼트 진입

#### 🟠 Tukysa HER2+ 유방암 유지요법 승인 — Pfizer, 유지요법 시장 공략

**헤드라인**: Pfizer Tukysa(tucatinib), HER2 양성 전이성 유방암 1차 유지요법으로 FDA 승인 (Oct 7)

**배경**:
Tukysa는 HER2를 타깃으로 하는 소분자 타이로신 키나제 억제제(TKI)로, 트라스투주맙 및 페르투주맙과 병용하여 쓰인다. 기존에는 2차 이상 HER2+ 전이성 유방암에서 사용되었으나, 이번에는 1차 유지요법 적응증으로 확장된 것. HER2CLIMB-05 Phase 3 trial이 근거.

**데이터 요약**:
- Trial: HER2CLIMB-05 Phase 3
- mPFS: Tukysa 군 **24.9개월** vs 위약 군 **16.3개월**
- 임상적으로 의미 있는 8.6개월 연장

**BD 관점**:
1차 유지요법 적응증은 환자 수와 치료 기간이 모두 늘어나는 황금 포지션. Pfizer의 HER2 franchise가 2차에서 1차로 올라오면서 시장 점유율 확대. ADC 경쟁자인 T-DXd(Enhertu)와의 포지셔닝 차별화가 관건.

**경쟁 구도**:
- AstraZeneca/Daiichi Sankyo Enhertu (T-DXd): HER2 ADC, 2차 표준 치료
- Roche/Genentech Kadcyla (T-DM1): 1차 보조요법
- Pfizer Tukysa: 이번 승인으로 1차 유지요법 포지션 확보

#### 🔴 [TOP] Iza-bren TNBC Phase 3 강력한 OS 개선 — BMS의 BsADC 시대 개막

**헤드라인**: BMS의 izalontamab brengitecan(iza-bren), TNBC Phase 3에서 전체생존율 유의미 개선 — 세계 최초 BsADC의 역사적 데이터

**배경**:
[[ADC]] Iza-bren은 EGFR과 HER3를 동시에 타깃하는 **bispecific ADC(BsADC)**, 즉 이중특이성 항체에 약물이 붙은 형태다. 기존 ADC는 하나의 항원만 타깃하지만, iza-bren은 두 수용체를 동시 결합하여 더 넓은 환자군에서 작용하고 내성 발생을 줄일 수 있다. Payload는 DXd(토포이소머레이즈 I 억제제)로, Enhertu와 동일 계열이다.

**데이터 요약 (PANKU-Breast02, Phase 3 — ASCO 2026 LBA)**:
- 대상: 치료 경험 있는 전이성 TNBC
- **mPFS**: 8.5개월 (iza-bren) vs 3.1개월 (TPC)
- **mOS**: 15.9개월 (iza-bren) vs 12.5개월 (TPC), **HR 0.60** (p 유의미)
- ORR: 대략 35% 이상 (추가 확인 필요)
- ESCC(식도암) 병용 데이터: OS 9.8 vs 7.2개월, PFS 4.2 vs 2.0개월, ORR 35.3% vs 13.1%

**BD 관점**:
- BMS는 이미 중국 Biokin을 통해 iza-bren을 도입 → 글로벌 상업화 단계로 진입
- TNBC와 ESCC에서 양쪽 모두 Phase 3 양성 → 복수 적응증 동시 허가 전략
- SCLC (소세포폐암) Phase 3도 진행 중 → 향후 3개 적응증 동시 보유 잠재력
- [[BsADC]]라는 새 플랫폼 범주를 선점하는 경쟁자가 BMS

**경쟁 구도**:
- AstraZeneca/Daiichi Sankyo Enhertu (T-DXd): TNBC 2차 표준치료
- Gilead Trodelvy (sacituzumab govitecan): TNBC 표준치료
- Daiichi Sankyo datopotamab deruxtecan (Dato-DXd): TNBC 진입 경쟁

#### 🟠 Ivonescimab BLA Accepted — PD-1/VEGF 이중항체의 미국 허가 심사 개시

**헤드라인**: Akeso/Summit Therapeutics의 ivonescimab, EGFR 변이 전처치 NSCLC에서 FDA BLA 접수

**배경**:
Ivonescimab은 PD-1과 VEGF-A를 동시에 차단하는 bispecific antibody. 기존에는 anti-PD-1/PD-L1 단독이 면역 checkpoint를 막았지만, VEGF 차단까지 동시에 하면 혈관신생(angiogenesis)과 면역억제를 동시에 공략할 수 있다.

**데이터 요약 (HARMONi trial)**:
- Population: EGFR 변이, 전처치 NSCLC
- **PFS HR: 0.52** — pembrolizumab 대비 48% 진행 위험 감소
- AstraZeneca가 October 5 Summit Therapeutics에 **$2B 지분 투자** 단행

**BD 관점**:
AstraZeneca의 $2B 지분 투자는 ivonescimab 상업화 지원이 목적. 이미 검증된 bispecific 플랫폼을 보유한 중국 바이오텍(Akeso)이 글로벌 파트너를 통해 상업화하는 China Out-licensing의 대표 사례. BMS 관점에서는 Opdivo의 NSCLC 포지션에 직접적 위협.

**경쟁 구도**:
- MSD Keytruda: PD-1 단독, NSCLC 1차 표준
- BMS Opdivo + Yervoy: NSCLC 1차 허가
- Roche/Genentech Tecentriq: NSCLC 1차

#### 🟡 Iberdomide Phase 3 EXCALIBER-RRMM 성공 — BMS 혈액종양 파이프라인 강화

**헤드라인**: BMS ZENBEXUS(iberdomide) + daratumumab + dex, RRMM Phase 3에서 2차 dual primary endpoint 충족 (Oct 8)

**배경**:
Iberdomide는 CELMoD(Cereblon E3 Ligase Modulator)로, Revlimid(lenalidomide)보다 강력한 차세대 면역조절제. Revlimid의 특허 만료 이후 BMS가 혈액종양에서 시장 지위를 유지하려는 핵심 전략 자산. Daratumumab(CD38 단클론항체)와의 병용으로 다중 기전을 동시에 공략.

**데이터 요약**:
- Trial: EXCALIBER-RRMM Phase 3
- 2차 dual primary endpoint 충족 (PFS 또는 OS — 구체적 수치 원발 데이터 확인 필요)
- 1차 dual primary endpoint는 이미 충족된 상태

**BD 관점**:
BMS의 Revlimid LOE 대응 전략의 핵심 자산. 이베르도미드 성공 시 Revlimid를 대체하는 next-generation CELMoD로서 BMS의 다발성 골수종 franchise를 최소 10년 이상 연장 가능. 경쟁사 대비 플랫폼 우위 유지.

**경쟁 구도**:
- J&J Darzalex (daratumumab) 기반 regimen: 시장 지배적
- BMS CAR-T (ide-cel, liso-cel): 후기 치료선 포지셔닝
- MSD/Pfizer bispecific 접근법

#### 🔴 ABL Bio × Eli Lilly — $2.6B Grabody-B Blood-Brain Barrier 플랫폼 딜

**딜 개요**:
ABL Bio가 보유한 **Grabody-B 플랫폼**(혈뇌장벽 통과 기술)을 Eli Lilly에 라이선스 아웃. 뇌 질환 치료제 개발을 위한 플랫폼 기술 딜.

**딜 구조**:
- **Total deal value: $2.6B**
- 계약금(upfront) + 개발/상업화 milestone 구조
- Royalty rate: 미공개

**왜 이 딜인가**:
Eli Lilly는 알츠하이머(donanemab 승인 후), 파킨슨, 기타 CNS 분야에서 aggressive expansion 중. 혈뇌장벽(BBB) 통과는 CNS 신약 개발의 가장 큰 기술적 장벽. Grabody-B는 LRP1 수용체를 이용해 항체를 뇌로 전달하는 독창적 플랫폼.

**밸류에이션 근거**:
$2.6B total deal = 플랫폼 기술 딜로서 매우 큰 규모. Platform deal의 특성상 단일 화합물이 아니라 복수 파이프라인 적용 가능성 반영. CNS 시장 규모(알츠하이머만 $10B+)와 기술 희소성이 premium 결정.

**리스크 요인**:
- BBB 통과 기술의 임상 효과 검증 아직 초기
- CNS 임상은 실패율이 다른 영역보다 현저히 높음 (~85% Phase 1-3 실패율)
- Grabody-B 플랫폼의 다양한 항체 적용 가능성은 아직 실험적

## Section 4: 오늘의 BD 역량 심화 (BD Competency Deep Dive)

### 오늘의 주제: [[Deal Valuation]] — rNPV로 한미-Genentech 딜 가치를 분해하기

---

**1. 오늘의 BD 스킬**: **rNPV (Risk-adjusted Net Present Value) 기반 딜 밸류에이션**

**2. 실제 사례**: 한미약품 HM17321 × Genentech 딜 ($190M upfront + ~$2.5B total)

---

**3. 개념 설명**:

rNPV(리스크 보정 NPV)는 신약 개발 딜 밸류에이션의 핵심 도구다. 일반 NPV에 각 임상 단계별 성공 확률(PoS, Probability of Success)을 곱해 '기대값(expected value)'으로 환산한다. Emma의 NPV 지식 + 임상 성공 확률 데이터를 결합하면 딜 가격이 '비싼지, 싼지'를 판단할 수 있다.

핵심 공식:
```
rNPV = Σ [Cash Flow(t) × PoS(cumulative to t) / (1+r)^t] - Investment
```

**4. 실전 적용**: HM17321 딜을 step-by-step으로

**Step 1: 시장 기회 (Peak Sales) 추정**
- Target: 비만 / GLP-1+GIP 이중작용제
- GLP-1 전체 시장 2030년 예상: $100B+
- HM17321의 경쟁 환경: Ozempic, Wegovy, Mounjaro, Zepbound + 수십 개 follow-on
- 현실적 market share가 1-2%라도 → peak sales $1B-$2B 가능

**Step 2: 확률 보정 (Phase별 PoS)**
- Industry average success rates:
  - Phase 1 → 승인: **~10-12%**
  - Phase 2 → 승인: **~25-30%**
  - Phase 3 → 승인: **~60-70%**
- HM17321이 Phase 1 단계라면: 전체 PoS ≈ 10-12%
- Peak Sales $1.5B × 10% PoS = **rNPV 기여분 $150M** (매우 단순화)

**Step 3: Royalty로 바꾸기**
- 라이선서(한미)가 받는 royalty rate 가정: 8-12% (typical for Phase 1 deal)
- Peak Sales $1.5B × 12% royalty × 10 years patent lifetime = $1.8B royalty stream
- Discounting(r=8%) + PoS 10% = rNPV of royalties ≈ $180-250M

**Step 4: Upfront과의 비교**
- Genentech이 $190M upfront 지불 = 한미 rNPV와 비슷한 수준
- 즉 Genentech은 "기대 royalty 가치만큼 upfront를 선지급" → 합리적 가격
- Total $2.5B = 최대 성공 시나리오(Phase 3 성공 + 승인 + 블록버스터) 달성 시 지급

**Step 5: Buyer(Genentech) 관점 Check**
- $190M upfront + milestone + royalty vs. 자체 GLP-1 개발 비용 (Phase 1부터 시작하면 $500M+)
- "Buy vs. Build" 비교: 외부 조달이 훨씬 싸고 빠름 → 딜 성사 논리

**5. Emma를 위한 연습**:
